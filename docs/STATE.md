# FinScope 项目状态与验证范围

记录日期：2026-10-03（Asia/Shanghai）。

## 当前定位

用户画像驱动的金融需求分析平台。以**用户确认的结构化跨会话画像**为输入，由程序完成确定性收支计算、模拟产品硬约束过滤与版本化条款检索；模型承担受限的字段抽取与带引用的条款答复。

数据集为单机可复现的完整合成快照：20 个演示用户、9 条模拟产品、54 条条款、20 组预先标注的跨会话序列。目录不含收益率，平台输出是需求分析结果，不接入资金操作。

- **100 项测试全部通过，20.108 秒**：领域 39、记忆服务 27、Agent 19、ASGI 网页 13、序列评测 2。

- Alice 标签：月结余 1500.00 元、差额 7000.00 元、5 个完整月份；期限 6 个月可达、3 个月不可达；唯一通过全部硬约束的候选为 FS-CASH，规则分 100。Bob 具有不同的确认约束与候选，排序有独立预期标签。
- 最终 wheel 在源码目录之外的全新环境中、仅使用 **38 项锁定依赖** 安装成功，`pip check` 通过。
- wheel 内 **15 个 Python 模块 + 3 个 JSON** 与最终源码逐字节一致。
- 独立安装验证覆盖 CLI、MCP demo（13 次工具调用）、持久化恢复、期限更新、删除、20 组序列，以及实际 HTTP 登录与条款引用预览。
- 凭据扫描无异常；仓库不发布 `runs`、`dist`、`build`、虚拟环境、数据库、密钥或真实个人资料。

## 验证范围与数据口径

- 测试与外部服务之间用 `httpx.MockTransport` 隔离，逐项验证非法字段、无依据引用与错误响应路径；真实服务接入后的评测集见[演进路线](ROADMAP.md)。
- 跨平台 CI 覆盖 Ubuntu / Windows × Python 3.11 / 3.12，包含依赖安装、全部测试、打包数据一致性、wheel 构建与源码目录外安装、`demo`、20 组序列以及启动 HTTP 服务；具体结果以仓库 Actions 为准。
- 所有产品、用户与费用数据是合成演示数据；无收益率、无实际资金操作。
- 检索阶段为词项/字符匹配，不含向量索引；扩展方向见[演进路线](ROADMAP.md)。
- 引用校验保证来源 ID 与字面片段合法，模型问答结果标记 `pending_review` 与 `semantic_support_verified=false`，交由人工核查。
- 删除作用于应用数据库：清理该用户的画像、字段来源、历史、提议、反馈与个人运行记录，并递增记忆代次。
- 规则评分权重是显式设计配置并随结果返回；在有有效真实交互标签前，不报告 Recall@k / NDCG@k。
- 网页使用本机演示账号选择器；面向多用户部署时接入外部身份提供方的方案见[演进路线](ROADMAP.md)。

## 复现命令

在项目目录使用：

```powershell
.\.venv\Scripts\python.exe -m finscope serve --mode fixture
# 浏览器打开 http://127.0.0.1:7862
.\.venv\Scripts\python.exe -m finscope demo --db runs/demo.sqlite --mode fixture
.\.venv\Scripts\python.exe -m finscope evaluate --output runs/evaluation.json
```
