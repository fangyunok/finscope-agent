# FinScope 项目状态与验证范围

记录日期：2026-10-03（Asia/Shanghai）。本文说明哪些行为已经过验证、哪些尚未验证，便于复现与评估。

## 当前定位

用户画像驱动的金融需求分析演示平台。以**用户确认的结构化跨会话画像**为输入，由程序完成确定性收支计算、模拟产品硬约束过滤与版本化条款检索；模型只承担受限的字段抽取与带引用的条款答复。

所有用户、产品、费用与风险标签均为合成演示数据，目录不含收益率。平台输出是模拟需求分析，没有资金操作。

## 已验证

- **100 项测试全部通过，20.108 秒**：领域 39、记忆服务 27、Agent 19、ASGI 网页 13、序列评测 2。
- **20 组预先标注的独立模拟跨会话序列 20 / 20 通过**，报告见 `evaluation_report.json`；执行 83 次真实本地 MCP 调用，0 次模型调用。
- 真实浏览器流程：填写模拟资料 → 提议 → 勾选确认 → 计算分析 → 期限修改 → 再分析 → 删除 → 旧运行不可访问、新任务回到 `needs_profile`；浏览器异常 0。
- Alice 标签：月结余 1500.00 元、差额 7000.00 元、5 个完整月份；期限 6 个月可达、3 个月不可达；唯一通过全部硬约束的候选为 FS-CASH，规则分 100。Bob 具有不同的确认约束与候选，排序有独立预期标签。
- 最终 wheel 在源码目录之外的全新环境中、仅使用 **38 项锁定依赖** 安装成功，`pip check` 通过。
- wheel 内 **15 个 Python 模块 + 3 个 JSON** 与最终源码逐字节一致。
- 独立安装验证覆盖 CLI、MCP demo（13 次工具调用）、持久化恢复、期限更新、删除、20 组序列，以及实际 HTTP 登录与条款引用预览。
- 凭据扫描无异常；不发布 `runs`、`dist`、`build`、虚拟环境、数据库、密钥或真实个人资料。
- 截图 `docs/assets/workbench.png` 取自真实本地页面。

## 未验证与范围

- **真实 Qwen 端到端调用尚未验证**；HTTP 模型测试使用 `httpx.MockTransport`，不能当成模型质量成绩。接入后需要另建带人工标签的中文字段抽取与条款问题集，检查引用语义支持，并记录模型名、配置、失败率、延迟与 token 用量。
- 跨平台 CI 已配置（Ubuntu / Windows × Python 3.11 / 3.12），覆盖依赖安装、全部测试、打包数据一致性、wheel 构建与源码目录外安装、`demo`、20 组序列及启动 HTTP 服务；**具体结果以仓库 Actions 为准**。
- 所有产品、用户与费用数据是合成演示数据；无收益率、无实际资金操作、无训练排序模型。
- 检索是关键词 / 字符基线，**没有 embedding 或向量索引**；只实现确认过的结构化 Memory，尚未比较「无记忆」与「最近对话历史」两种基线（原方案提出，未完成）。
- 引用校验证明来源 ID 与字面片段合法，**不证明语义**；模型问答标记 `pending_review` 与 `semantic_support_verified=false`。
- 删除是应用数据库逻辑范围内的删除，不声称清除备份、磁盘取证残留或外部模型服务日志。
- 规则评分权重是显式设计配置，不是训练结果；没有有效真实交互标签时，不报告 Recall@k / NDCG@k，也不声称推荐质量。
- 网页使用本地演示账号选择器，不是生产身份认证；真实多用户部署需要独立身份提供方、访问控制与备份策略。

## 复现命令

在项目目录使用：

```powershell
.\.venv\Scripts\python.exe -m finscope serve --mode fixture
# 浏览器打开 http://127.0.0.1:7862
.\.venv\Scripts\python.exe -m finscope demo --db runs/demo.sqlite --mode fixture
.\.venv\Scripts\python.exe -m finscope evaluate --output runs/evaluation.json
```
